# Roadmap

Honest about what exists and what doesn't. See [docs/STATUS.md](docs/STATUS.md) for
the detailed tracker.

## Next

- **Inbox adapter**: read saved-search alert e-mails from Ricardo, tutti.ch and others
  that the user forwards (IMAP), the permitted route for Swiss classifieds.
- **Retail prices for market value**: optional official price sources (e.g. a search API
  the user brings a key for) to compare second-hand asking prices with new prices.
- **Web Push** notifications as an alternative to Telegram.
- **Undo for destructive actions** beyond feedback (deleted searches).
- **Bundle math**: value bundles item by item against the user's wishlist accessories.

## Later

- Amazon Product Advertising adapter for users with Associates access.
- OpenAI-compatible endpoints (local models) with capability metadata.
- Multi-currency conversion with an explicit, user-visible rate source.
- Two-factor authentication (TOTP / passkeys).
- Translations (German, French, Italian).

## Not planned

- Scraping marketplaces against their terms, or working around bot protection.
- Automatic purchases.
