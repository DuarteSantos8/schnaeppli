# Brand

**Name:** Schnäppli, Swiss German for a real bargain (good, not cheap). Say it
SHNAP-lee, [ˈʃnæp.li]. Written `schnaeppli` where an ä can't go (repo, images, env vars).
In running text it's "Schnäppli"; the wordmark is lowercase.

**Mark:** a geometric single-storey *ä* whose dots are a face: one open eye, one winking.
White on cobalt. The wordmark is Geist Bold, converted to outlines, with the same winking
dots in cobalt over the *a*. Files in `brand/`: `mark.svg` (rounded icon), `app-icon.svg`
(square, platforms round the corners), `app-icon-maskable.svg`, `favicon.svg`,
`wordmark.svg`, `wordmark-dark.svg`. Don't redraw them; scale the SVGs.

**Colour.** The interface itself stays colourless so listing photos carry the colour.
| Role | Value |
| --- | --- |
| Ground (warm stone) | `#f4f3f1` |
| Surface | `#ffffff` |
| Ink | `#0a0a0a` |
| Muted text | `#66645f` |
| Primary action | `#141414` (near-black) |
| **Score / data hue (cobalt)** | `#1d5fbf` |
| Positive / negative / warning | `#2e7d32` / `#c4242a` / `#92400e` (small signals only) |

Cobalt appears on the Deal Score and the current period in charts, and nowhere in the
chrome. App icon: white winking ä on a cobalt field.

**Type:** Geist (variable, bundled), tabular figures for every number. Titles 22-24px
semibold, body 14-15px, labels 12-13px. No tracked capitals, no monospace outside code.

**Shape:** cards 8px radius, controls 6px, 1px borders or a tone step, no resting shadows,
no gradients.

**Voice:** plain, short, honest. "Estimated" when it is. Never "AI-powered magic".
